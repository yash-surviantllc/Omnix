# OMNIX - Frontend Application

This is the React-based frontend application for the OMNIX Manufacturing Operations System.

## Technical Stack

- **Framework**: React with Vite
- **Language**: TypeScript
- **Styling**: TailwindCSS & shadcn/ui
- **State Management**: Zustand
- **Real-time**: Socket.io-client
- **Data Fetching**: Axios
- **Form Management**: React Hook Form with Zod

## Key Features

- **Dynamic WIP Board**: Kanban interface for tracking production stages.
- **Inventory Dashboard**: Real-time stock visibility and transaction history.
- **Role-Based Access**: Specialized views for Administrators and Workers.
- **Localization**: Full support for Hindi and English.

## Running the code

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
